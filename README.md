# C++ Practice

## Project Description
A collection of beginner C++ programs I wrote while learning programming fundamentals and problem-solving.

## Technologies Used
- C++

## Folder Structure
- `basics/` - input/output, conditions, variables
- `loops/` - for loops, patterns, tables
- `arrays/` - working with arrays
- `strings/` - string handling
- `problem-solving/` - small logic problems

## How to Run
```
g++ loops/factorial.cpp -o factorial
./factorial        (on Windows: factorial.exe)
```

## What I Learned
Loops, conditions, arrays, strings, and basic problem-solving logic.
